Protection checklist

What leaves your PC

Solus itself sends no telemetry or usage data. There is no Solus account or server.
Search suggestions (if on) send what you type in the address bar to your search engine.
Microsoft Defender SmartScreen (if on) checks site and download reputations with Microsoft. The engine (Microsoft Edge WebView2) may also send Windows diagnostic data according to your Windows privacy settings.
Filter list updates download from easylist.to, GitHub and fanboy.co.nz every few days. Update checks contact GitHub daily (can be turned off).
The AI assistant sends your question (and the page text, if you allow it) to Anthropic or Groq only when you ask it something.
Sync writes encrypted files to your own cloud-drive folder; your cloud provider can't read them.
